# ระบบให้คะแนนกรรมการ (Vocational Skill Judging System – VSJS)

เว็บแอปสำหรับกรรมการบันทึกคะแนนการแข่งขันทักษะวิชาชีพ (ปวส./ปวช.) รองรับหลาย **ทักษะ** ในระบบเดียว โดยค่าเริ่มต้นมี 2 ทักษะ:

- **ปวส. - ทักษะเทคโนโลยีสารสนเทศด้านโปรแกรมและเครือข่ายด้วยกระบวนการ DevOps** (ส่วนที่ 1–5 รวม 100 คะแนน + โจทย์พิเศษ 10 คะแนนแยกไว้จัดอันดับ)
- **ปวช. - ทักษะการพัฒนาระบบประเมินบุคลากรด้วยระบบเทคโนโลยีสารสนเทศสมัยใหม่** (ส่วนที่ 1–9 รวม 100 คะแนน)

แต่ละทักษะมีทีม กรรมการที่รับผิดชอบ กลุ่มเกณฑ์การให้คะแนน/เกณฑ์ย่อย และสรุปคะแนนแยกจากกันโดยสิ้นเชิง สามารถเพิ่มทักษะใหม่ได้จากเมนู "ทักษะ" (Admin เท่านั้น)

ระบบนี้ถูกออกแบบให้ **ติดตั้งและรันบนเครื่องคอมพิวเตอร์ที่งานแข่งขัน** (เช่น โน้ตบุ๊กของฝ่ายจัดการแข่งขัน/ประธานกรรมการ) แล้วให้กรรมการและกรรมการตรวจแต่ละคนเปิดเบราว์เซอร์จากมือถือ/โน้ตบุ๊กของตัวเอง เชื่อมต่อผ่าน Wi-Fi/LAN วงเดียวกันมาที่เครื่องนี้ — **ไม่จำเป็นต้องมีอินเทอร์เน็ต** ขณะแข่งขัน (ยกเว้นตอนโหลดฟอนต์ Saraban ครั้งแรกของแต่ละเครื่องที่เข้าใช้)

## 👥 บทบาทผู้ใช้งาน

| บทบาท | สิทธิ์การใช้งาน |
|---|---|
| **⚙️ ผู้ดูแลระบบ (Admin)** | จัดการทักษะ, กรรมการ, กลุ่มเกณฑ์/เกณฑ์ย่อย, ทีมผู้เข้าแข่งขัน, ดูสรุปคะแนนทุกทีม, พิมพ์ใบประเมินคะแนน |
| **👑 ประธานกรรมการ** (ตำแหน่งกรรมการ) | ให้คะแนนได้ตามปกติ **+** ดูสรุปคะแนน **+** มอบหมายว่ากรรมการแต่ละคนให้คะแนนทีมใดได้บ้าง **+** พิมพ์ใบประเมินคะแนน |
| **🎖️/⚖️/📋/📝 กรรมการ** (ตำแหน่งอื่น ๆ) | Login แล้วให้คะแนนทีมต่าง ๆ เฉพาะในกลุ่มเกณฑ์ที่ตนรับผิดชอบ |

ตำแหน่งกรรมการที่กำหนดได้: ประธานกรรมการ, รองประธานกรรมการ, กรรมการ, กรรมการและเลขานุการ, ผู้ช่วยกรรมการและเลขานุการ

## 🖥️ ข้อกำหนดของเครื่อง (สำหรับเครื่องที่จะรันระบบ)

ไม่จำเป็นต้องเป็นเซิร์ฟเวอร์จริง ใช้โน้ตบุ๊ก/พีซีทั่วไปได้ ขอเพียง:

- Windows 10/11 (64-bit), หรือ macOS / Linux ก็ได้
- ติดตั้ง **[Docker Desktop](https://www.docker.com/products/docker-desktop/)** (บน Windows ต้องเปิดใช้ WSL2 ตามที่ตัวติดตั้ง Docker Desktop แนะนำ)
- RAM อย่างน้อย 4 GB ว่าง, พื้นที่ว่างอย่างน้อย 2 GB
- เชื่อมต่ออยู่ใน Wi-Fi/LAN วงเดียวกับอุปกรณ์ของกรรมการทุกคน (เช่น ปล่อย Wi-Fi hotspot จากเครื่องนี้ หรือใช้เร้าเตอร์ของสถานที่จัดงาน)

## 🚀 วิธีติดตั้งและเริ่มใช้งาน (เครื่องกรรมการ / เครื่องเซิร์ฟเวอร์ประจำสนามแข่ง)

### 1. ติดตั้ง Docker Desktop

ดาวน์โหลดและติดตั้งจาก https://www.docker.com/products/docker-desktop/ แล้วเปิดโปรแกรม Docker Desktop ทิ้งไว้ (ไอคอนวาฬที่มุมล่างขวาต้องขึ้นสถานะ "Running")

### 2. ดึงโค้ดระบบลงเครื่อง

ถ้าเครื่องมี Git ติดตั้งอยู่แล้ว (ต้องมีสิทธิ์เข้าถึง repository นี้ เพราะเป็น private repo):

```bash
git clone https://github.com/mangcom/Vocational-Skill-Judging-System.git
cd Vocational-Skill-Judging-System
```

หรือถ้าไม่สะดวกใช้ Git ให้ดาวน์โหลดเป็นไฟล์ ZIP จากหน้า GitHub ของ repo (ปุ่ม **Code → Download ZIP**) แล้วแตกไฟล์ไว้ในเครื่อง

### 3. ตั้งค่าไฟล์ `.env`

คัดลอกไฟล์ตัวอย่างไว้ก่อน (ค่าด้านในเป็นเพียงค่าเริ่มต้น/fallback — จะตั้งรหัสผ่าน Admin และตรวจสอบการเชื่อมต่อฐานข้อมูลจริงผ่านหน้าเว็บ **`/install.php`** ในขั้นตอนที่ 7 แทนการแก้ไฟล์เอง):

```bash
cp .env.example .env
```

ถ้าต้องการเปลี่ยนพอร์ตที่ใช้เปิดเว็บ (ค่าเริ่มต้น `8080`) หรือรหัสผ่านระดับ root ของฐานข้อมูล (`DB_ROOT_PASSWORD`) ให้แก้ในไฟล์ `.env` ก่อนรันขั้นตอนถัดไป (ค่าที่เหลือ — `DB_NAME`/`DB_USER`/`DB_PASSWORD`/บัญชี Admin — ตั้งผ่านหน้าเว็บได้เลย ไม่จำเป็นต้องแก้ในไฟล์ล่วงหน้า):

```
APP_PORT=8080
DB_ROOT_PASSWORD=<ตั้งรหัสผ่านใหม่>
```

### 4. สั่งสร้างและรันระบบ

```bash
docker compose up -d --build
```

รอสักครู่ (ครั้งแรกจะดาวน์โหลด image และสร้างฐานข้อมูล ~1-2 นาที) ตรวจสอบว่าเริ่มสำเร็จด้วย:

```bash
docker compose logs app --tail 30
```

ควรเห็นบรรทัด `[migrate] done` และ Apache เริ่มทำงาน (ไม่มี error สีแดง)

### 5. ทดสอบเปิดจากเครื่องตัวเอง

เปิดเบราว์เซอร์ไปที่ `http://localhost:8080` ควรเห็นหน้า Login

### 6. หา IP ของเครื่องนี้ เพื่อให้กรรมการคนอื่นเชื่อมต่อ

บน Windows เปิด PowerShell แล้วพิมพ์:

```powershell
ipconfig
```

ดูที่ `IPv4 Address` ของการ์ดเครือข่ายที่ต่อ Wi-Fi/LAN เดียวกับกรรมการ (เช่น `192.168.1.50`) แล้วแจ้งให้กรรมการแต่ละคนเปิดเบราว์เซอร์ (มือถือ/โน้ตบุ๊กของตัวเอง) ไปที่:

```
http://192.168.1.50:8080
```

(แทน `192.168.1.50` ด้วย IP จริงของเครื่องที่รันระบบ)

> ⚠️ **ถ้าเปิดจากเครื่องอื่นแล้วเข้าไม่ได้** ให้ตรวจสอบ **Windows Firewall** ของเครื่องที่รันระบบ — ไปที่ Windows Defender Firewall → Allow an app through firewall → อนุญาต "Docker Desktop Backend" ทั้ง Private และ Public network หรือเปิดพอร์ต 8080 (TCP) แบบ Inbound Rule ชั่วคราวระหว่างงานแข่งขัน

### 7. ติดตั้งระบบผ่านเว็บ (`/install.php`) — ตั้งรหัสผ่าน Admin และตรวจการเชื่อมต่อฐานข้อมูล

เปิดเบราว์เซอร์ไปที่ `http://localhost:8080/install.php` (หน้านี้จะแสดง **เฉพาะครั้งแรก** ที่ยังไม่มีบัญชี Admin ในระบบ) แล้วกรอก:

- **Database Hostname** — ค่าเริ่มต้นอ่านจาก `.env` (ใช้ `db` ตามเดิมถ้าใช้ docker-compose ที่แนบมา)
- **Database Name / User / Password** — ปล่อยเป็นค่าเริ่มต้นได้ถ้าใช้ฐานข้อมูลที่แนบมากับ docker-compose
- **Admin Username / Password** — ตั้งเป็นของจริง (ห้ามใช้ `admin` / `Admin@2569` ตามตัวอย่างในงานจริง)

กด **🚀 ติดตั้งระบบ** ระบบจะสร้างตารางฐานข้อมูล สร้างบัญชี Admin ตามที่กรอก และบันทึกค่าทั้งหมดลงไฟล์ `.env` ให้อัตโนมัติ จากนั้นเข้าสู่ระบบด้วยบัญชี Admin ที่เพิ่งตั้งได้ทันที

> หน้า `/install.php` จะถูกล็อกอัตโนมัติหลังติดตั้งสำเร็จ (เข้าซ้ำจะเด้งไปหน้า Login) ถ้าต้องการเปลี่ยนค่าการเชื่อมต่อฐานข้อมูล/บัญชี Admin ภายหลัง ให้ Login ด้วยบัญชี Admin ปัจจุบันก่อน แล้วเปิด `/install.php` อีกครั้ง

### 8. (ถ้ามีไฟล์สำรองข้อมูลจากเครื่องอื่น) นำเข้าข้อมูลทันทีผ่านเมนู Import/Export

ถ้าเตรียมข้อมูลทักษะ/กรรมการ/ทีมไว้แล้วจากเครื่องอื่น ไม่ต้องตั้งค่าใหม่ทั้งหมด — ไปที่เมนู **🗄️ Import/Export** หลัง Login แล้วอัปโหลดไฟล์ `.zip` ที่ Export มาจากเครื่องเดิม ระบบจะนำเข้าข้อมูลทั้งหมด (รวมไฟล์เกณฑ์ที่เคยอัปโหลด) มาแทนที่ข้อมูลเริ่มต้นให้ทันที (ดูรายละเอียดที่หัวข้อ [📦 สำรอง/ย้ายข้อมูล (Import / Export)](#-สำรองย้ายข้อมูล-import--export) ด้านล่าง)

## 🧭 ลำดับการเตรียมระบบก่อนวันแข่งขัน (สำหรับ Admin)

1. **ทักษะ** — ตรวจสอบ/เพิ่มทักษะที่จะใช้แข่งขัน อัปโหลดไฟล์เกณฑ์การแข่งขัน (PDF) และรายละเอียดเพิ่มเติมได้ที่หน้านี้
2. **กลุ่มเกณฑ์การให้คะแนน** — ระบบเตรียมเกณฑ์ไว้ล่วงหน้าตามไฟล์โจทย์ แก้ไข/เพิ่ม/ลบเกณฑ์ย่อยได้ที่เมนูนี้
   - **สำคัญ:** หัวข้อ "โจทย์พิเศษ" (ฝั่ง DevOps) ต้องแก้ไขเนื้อหาให้ตรงกับโจทย์ที่จับฉลากได้จริงก่อนเริ่มแข่งขัน เพราะเกณฑ์แต่ละโจทย์แตกต่างกัน
3. **ทีมผู้เข้าแข่งขัน** — เพิ่ม/แก้ไขชื่อทีมและโจทย์ที่จับได้
4. **กรรมการ** — เพิ่มกรรมการ ตั้งชื่อผู้ใช้/รหัสผ่าน กำหนด **ตำแหน่ง** และ **กลุ่มเกณฑ์ที่รับผิดชอบ** (กรรมการจะเห็นและให้คะแนนได้เฉพาะกลุ่มเกณฑ์ที่ได้รับมอบหมาย) — มีตัวกรองตามทักษะในหน้านี้เมื่อมีหลายทักษะ
5. **มอบหมายทีม** (เมนูนี้ของประธานกรรมการ) — ถ้าต้องการจำกัดว่ากรรมการแต่ละคนให้คะแนนได้เฉพาะบางทีม ให้ตั้งที่เมนูนี้ (ถ้าไม่ตั้ง กรรมการจะให้คะแนนได้ทุกทีมในกลุ่มเกณฑ์ของตนตามปกติ)
6. **ใบให้คะแนน (สำรอง)** — พิมพ์/บันทึกเป็น PDF ใบประเมินคะแนนกระดาษไว้ล่วงหน้าเป็นแผนสำรอง กรณีระบบคอมพิวเตอร์ใช้งานไม่ได้ขณะแข่งขัน เลือกได้หลายคู่ทีม+กรรมการพร้อมกัน พิมพ์ครั้งเดียว

## ✍️ ขั้นตอนใช้งานสำหรับกรรมการ

1. Login ด้วยบัญชีที่ Admin สร้างให้ (ผ่านมือถือ/โน้ตบุ๊กของตัวเอง)
2. เลือกทีมที่ต้องการให้คะแนนจากหน้าหลัก
3. กรอกคะแนนแต่ละข้อ (0 ถึงคะแนนเต็มของข้อนั้น) ในกลุ่มเกณฑ์ที่รับผิดชอบ แล้วกด "บันทึกคะแนน" (มีตัวเลขคะแนนรวมสดอยู่มุมขวาบนระหว่างกรอก)
4. สามารถกลับมาแก้ไขคะแนนซ้ำได้ตลอดเวลาที่ยังไม่ปิดระบบ (ค่าล่าสุดจะถูกบันทึกทับ)

## 👑 ขั้นตอนเพิ่มเติมสำหรับประธานกรรมการ

- **ดูผลคะแนน** — ดูสรุปคะแนนรวมทุกทีมและรายละเอียดรายกรรมการได้เหมือน Admin
- **มอบหมายทีม** — ติ๊กเลือกว่ากรรมการแต่ละคนให้คะแนนทีมใดได้บ้าง
- **ใบให้คะแนน (สำรอง)** — พิมพ์ใบประเมินคะแนนกระดาษได้เช่นเดียวกับ Admin

## 📊 หลักการคำนวณคะแนนรวม

- คะแนนแต่ละข้อของทีม = **ค่าเฉลี่ย** ของคะแนนจากกรรมการทุกคนที่บันทึกไว้สำหรับข้อนั้น (ถ้ามีกรรมการมากกว่า 1 คนรับผิดชอบกลุ่มเกณฑ์เดียวกัน)
- คะแนนรวมของกลุ่มเกณฑ์ = ผลรวมคะแนนเฉลี่ยของทุกข้อในกลุ่มเกณฑ์นั้น
- คะแนนรวม 100 = ผลรวมคะแนนของกลุ่มเกณฑ์หลัก โดยไม่รวมโจทย์พิเศษ
- โจทย์พิเศษ (ฝั่ง DevOps, เต็ม 10) แยกออกจากคะแนน 100 ใช้สำหรับจัดอันดับเมื่อคะแนนรวมเท่ากันเท่านั้น

## ❓ คู่มือการใช้งาน (Help)

ทุกผู้ใช้งาน (Admin และกรรมการ) เห็นเมนู **❓ คู่มือการใช้งาน** บนแถบเมนูด้านบนหลัง Login
ซึ่งลิงก์ไปหน้า `help.php` ให้ดาวน์โหลด/เปิดดูคู่มือการใช้งานฉบับเต็มเป็น PDF (`php/src/public/assets/docs/user-manual.pdf`)
คู่มือมีทั้งส่วนของผู้ดูแลระบบและกรรมการ พร้อมภาพประกอบขั้นตอนการทำงานทีละขั้นและคำถามที่พบบ่อย

> หากต้องการปรับปรุงเนื้อหาคู่มือ ให้แก้ไขและ generate ไฟล์ PDF ใหม่ แล้วแทนที่ไฟล์ `php/src/public/assets/docs/user-manual.pdf`

## 📦 สำรอง/ย้ายข้อมูล (Import / Export)

เมนู **🗄️ Import/Export** (Admin เท่านั้น) ใช้สำหรับสำรองข้อมูลหรือย้ายข้อมูลทั้งระบบไปเครื่องอื่น โดยไม่ต้องตั้งค่าทักษะ/กรรมการ/ทีมใหม่ทีละอย่าง:

- **📤 Export** — ดาวน์โหลดไฟล์ `.zip` เดียวที่รวม `database.sql` (ฐานข้อมูลทั้งหมด: ทักษะ กรรมการ ทีม กลุ่มเกณฑ์/เกณฑ์ย่อย การมอบหมาย คะแนน) และโฟลเดอร์ `uploads/` (ไฟล์เกณฑ์การแข่งขันที่อัปโหลดไว้) ไว้ด้วยกัน ใช้สำรองข้อมูลเป็นระยะระหว่างงาน หรือก่อนย้ายไปติดตั้งที่เครื่องอื่น
- **📥 Import** — อัปโหลดไฟล์ `.zip` ที่ Export มา ระบบจะนำเข้าฐานข้อมูลและไฟล์ทั้งหมดให้อัตโนมัติ
  > ⚠️ **การ Import จะลบและแทนที่ข้อมูลปัจจุบันทั้งหมดในระบบ ไม่สามารถย้อนกลับได้** — ต้องติ๊กยืนยันก่อนทุกครั้ง แนะนำให้ Export ข้อมูลปัจจุบันเก็บไว้ก่อน Import เสมอ

**สำรองข้อมูลก่อนปิดระบบทุกครั้ง** ด้วยเมนู Export ด้านบน (หรือจะสั่ง `mysqldump` ตรง ๆ ก็ได้ถ้าต้องการ):

```bash
docker compose exec app mysqldump -h db -u judge_app -p"<DB_PASSWORD ใน .env>" judge_scoring > backup_judge_scoring.sql
```

ปิดระบบ (ข้อมูลยังอยู่ครบ เปิดใหม่ครั้งหน้าด้วย `docker compose up -d` ได้ทันที):

```bash
docker compose down
```

หากต้องการ **ล้างข้อมูลทั้งหมด** เพื่อเริ่มงานแข่งขันครั้งใหม่ตั้งแต่ต้น (ลบฐานข้อมูลถาวร ย้อนกลับไม่ได้):

```bash
docker compose down -v
```

## 🧰 แก้ปัญหาเบื้องต้น (Troubleshooting)

| อาการ | วิธีแก้ |
|---|---|
| `docker compose up` แล้ว container `app` วนรีสตาร์ทไม่หยุด | ดู log ด้วย `docker compose logs app --tail 50` มักเกิดจากฐานข้อมูลยังไม่พร้อม ลองรอ/รันซ้ำ หรือ `docker compose down -v` แล้วเริ่มใหม่ถ้าเพิ่งติดตั้งครั้งแรก (ยังไม่มีข้อมูลสำคัญ) |
| เปิด `http://localhost:8080` ไม่ได้ | ตรวจว่า Docker Desktop กำลัง Running และพอร์ต 8080 ไม่ถูกโปรแกรมอื่นใช้อยู่ (แก้ `APP_PORT` ใน `.env` แล้วรัน `docker compose up -d` ใหม่ได้) |
| เครื่องอื่นในวง Wi-Fi เปิดจาก IP เครื่องนี้ไม่ได้ | ตรวจ Windows Firewall ตามข้อ 6 ด้านบน และตรวจว่าทั้งสองเครื่องอยู่ใน Wi-Fi/LAN วงเดียวกันจริง |
| ลืมรหัสผ่าน Admin | เข้าถึงฐานข้อมูลโดยตรงผ่าน `docker compose exec db mariadb -uroot -p"<DB_ROOT_PASSWORD>" judge_scoring` แล้วอัปเดตค่า `password_hash` ด้วยค่าที่ hash มาจาก PHP (`password_hash('รหัสใหม่', PASSWORD_DEFAULT)`) |
| ฟอนต์ Saraban ไม่ขึ้น | ต้องมีอินเทอร์เน็ตตอนโหลดหน้าเว็บครั้งแรกของแต่ละเครื่อง (ฟอนต์โหลดจาก Google Fonts) ถ้าสถานที่จัดงานไม่มีอินเทอร์เน็ตเลย ฟอนต์จะ fallback เป็นฟอนต์ไทยเริ่มต้นของเครื่องนั้นแทน ใช้งานได้ปกติ |

## 🔒 หมายเหตุด้านความปลอดภัย

- รหัสผ่านถูกเก็บด้วย `password_hash` (bcrypt) ไม่มีการเก็บรหัสผ่านแบบ plain text
- ทุกฟอร์มมีการตรวจ CSRF token
- ทุกคำสั่ง SQL ใช้ Prepared Statement ป้องกัน SQL Injection
- โค้ดฝั่ง `app/` อยู่นอก DocumentRoot ของ Apache เข้าถึงผ่านเว็บไม่ได้โดยตรง
- ไฟล์เอกสารเกณฑ์ที่อัปโหลดเก็บนอก DocumentRoot เช่นกัน เข้าถึงได้เฉพาะผู้ที่ Login แล้วเท่านั้น (ผ่าน `download_criteria.php`)
- **อย่า commit ไฟล์ `.env` จริงขึ้น Git** (ถูกกันไว้ใน `.gitignore` แล้ว) และอย่าใช้รหัสผ่านตัวอย่างจาก `.env.example` ในงานจริง
