# ระบบให้คะแนนกรรมการ (Judge Scoring System)

เว็บแอปสำหรับให้กรรมการบันทึกคะแนนการแข่งขันทักษะวิชาชีพ รองรับหลาย **ประเภทการแข่งขัน (Division)** ในระบบเดียว โดยค่าเริ่มต้นมี 2 ประเภท:

- **ปวส. - ชุดโจทย์จับฉลาก DevOps** (ส่วนที่ 1–5 รวม 100 คะแนน + โจทย์พิเศษ 10 คะแนนแยกไว้จัดอันดับ)
- **ปวช. - ทักษะการพัฒนาระบบประเมินบุคลากรด้วยระบบเทคโนโลยีสารสนเทศสมัยใหม่** (ส่วนที่ 1–9 รวม 100 คะแนน)

แต่ละประเภทการแข่งขันมีทีม กรรมการที่รับผิดชอบ ทักษะ/เกณฑ์ และสรุปคะแนนแยกจากกันโดยสิ้นเชิง สามารถเพิ่มประเภทการแข่งขันใหม่ได้จากเมนู "ประเภทการแข่งขัน" (Admin เท่านั้น)

มีผู้ใช้ 2 บทบาท:

- **Admin** — เพิ่ม/แก้ไขกรรมการ (พร้อมกำหนดทักษะที่รับผิดชอบ), ทักษะและเกณฑ์ย่อย, ทีมผู้เข้าแข่งขัน และดูสรุปคะแนนทั้งหมด (ข้อมูลภายใน ไม่เปิดสาธารณะ)
- **กรรมการ (Judge)** — login แล้วให้คะแนนทีมต่าง ๆ เฉพาะในทักษะที่ตนรับผิดชอบ

## เทคโนโลยี

PHP 8.2 (Apache) + MariaDB 11 + Bootstrap 5 + SweetAlert2 — รันผ่าน Docker Compose เพื่อให้ติดตั้งซ้ำง่ายในระดับภาค/ระดับชาติ

## วิธีเริ่มใช้งาน

1. คัดลอกไฟล์ตั้งค่า แล้วแก้รหัสผ่านให้ปลอดภัยก่อนใช้งานจริง:

```bash
cp .env.example .env
```

2. สั่งสร้างและรันระบบ:

```bash
docker compose up -d --build
```

3. เปิดเบราว์เซอร์ไปที่ `http://<IP เครื่องเซิร์ฟเวอร์>:8080` (พอร์ตปรับได้ที่ `APP_PORT` ใน `.env`)

4. เข้าสู่ระบบด้วยบัญชี Admin เริ่มต้น (ตั้งไว้ใน `.env`):
   - ชื่อผู้ใช้: `admin`
   - รหัสผ่าน: `Admin@2569`

   **แนะนำให้เปลี่ยนรหัสผ่านทันทีหลังติดตั้งจริง** (ยังไม่มีหน้าเปลี่ยนรหัสผ่านตัวเอง ให้ Admin อีกคนช่วยแก้ไข หรือแก้ในฐานข้อมูลโดยตรง)

## ขั้นตอนใช้งานสำหรับ Admin

0. **ประเภทการแข่งขัน** — เลือก/สลับประเภทการแข่งขันที่จะจัดการได้จากแท็บด้านบนของหน้า "ทักษะ/เกณฑ์", "ทีมผู้เข้าแข่งขัน" และ "สรุปคะแนน" เพิ่มประเภทใหม่ได้จากเมนู "ประเภทการแข่งขัน"
1. **ทักษะ/เกณฑ์** — ระบบเตรียมเกณฑ์ไว้ล่วงหน้าตามไฟล์โจทย์ (ส่วนที่ 1 เครือข่าย, ส่วนที่ 2 DevOps, ส่วนที่ 3 IoT, ส่วนที่ 4 เว็บแอป, ส่วนที่ 5 การนำเสนอ, และโจทย์พิเศษ) สามารถแก้ไข/เพิ่ม/ลบเกณฑ์ย่อยได้ที่เมนู "ทักษะ/เกณฑ์" → "จัดการเกณฑ์ย่อย"
   - **สำคัญ:** หัวข้อ "โจทย์พิเศษ" ต้องแก้ไขเนื้อหาให้ตรงกับโจทย์ที่จับฉลากได้จริง (ColdGuard / MachineCare / StormWatch) ก่อนเริ่มแข่งขัน เพราะเกณฑ์แต่ละโจทย์แตกต่างกัน
2. **ทีมผู้เข้าแข่งขัน** — เพิ่ม/แก้ไขชื่อทีมและโจทย์ที่จับได้ (preload ไว้ 5 ทีมตามข้อกำหนดร่วม)
3. **กรรมการ** — เพิ่มกรรมการ ตั้งชื่อผู้ใช้/รหัสผ่าน และ **กำหนดทักษะที่รับผิดชอบ** (กรรมการจะเห็นและให้คะแนนได้เฉพาะทักษะที่ได้รับมอบหมาย)
4. **สรุปคะแนน** — ดูคะแนนรวมทุกทีม (เรียงอันดับ) และกดดูรายละเอียดคะแนนแยกตามกรรมการแต่ละคนต่อทีม หน้านี้มองเห็นได้เฉพาะ Admin เท่านั้น

## ขั้นตอนใช้งานสำหรับกรรมการ

1. Login ด้วยบัญชีที่ Admin สร้างให้
2. เลือกทีมที่ต้องการให้คะแนนจากหน้าหลัก
3. กรอกคะแนนแต่ละข้อ (0 ถึงคะแนนเต็มของข้อนั้น) ในทักษะที่รับผิดชอบ แล้วกด "บันทึกคะแนน"
4. สามารถกลับมาแก้ไขคะแนนซ้ำได้ตลอดเวลาที่ยังไม่ปิดระบบ (ค่าล่าสุดจะถูกบันทึกทับ)

## หลักการคำนวณคะแนนรวม

- คะแนนแต่ละข้อของทีม = **ค่าเฉลี่ย** ของคะแนนจากกรรมการทุกคนที่บันทึกไว้สำหรับข้อนั้น (ถ้ามีกรรมการมากกว่า 1 คนรับผิดชอบทักษะเดียวกัน)
- คะแนนรวมของทักษะ = ผลรวมคะแนนเฉลี่ยของทุกข้อในทักษะนั้น
- คะแนนรวม 100 = ผลรวมคะแนนของทักษะหลัก (ส่วนที่ 1–5) โดยไม่รวมโจทย์พิเศษ
- โจทย์พิเศษ (เต็ม 10) แยกออกจากคะแนน 100 ใช้สำหรับจัดอันดับเมื่อคะแนนรวมเท่ากันเท่านั้น

## โครงสร้างโปรเจกต์

```
judge-scoring/
├── docker-compose.yml
├── .env.example
├── php/
│   ├── Dockerfile
│   ├── docker-entrypoint.sh
│   └── src/
│       ├── app/        # ตรรกะฝั่งเซิร์ฟเวอร์ (DB, auth, migrate/seed, คำนวณคะแนน) — ไม่เปิดผ่านเว็บ
│       └── public/     # DocumentRoot จริงของ Apache
│           ├── admin/  # หน้าจัดการสำหรับ Admin
│           ├── judge/  # หน้าให้คะแนนสำหรับกรรมการ
│           └── includes/
```

## หมายเหตุด้านความปลอดภัย

- รหัสผ่านถูกเก็บด้วย `password_hash` (bcrypt) ไม่มีการเก็บรหัสผ่านแบบ plain text
- ทุกฟอร์มมีการตรวจ CSRF token
- ทุกคำสั่ง SQL ใช้ Prepared Statement ป้องกัน SQL Injection
- โค้ดฝั่ง `app/` อยู่นอก DocumentRoot ของ Apache เข้าถึงผ่านเว็บไม่ได้โดยตรง
- สำหรับใช้งานระดับภาค/ระดับชาติ แนะนำให้เปลี่ยนรหัสผ่านทั้งหมดใน `.env` ให้ปลอดภัย และพิจารณาเปิดใช้งาน HTTPS ผ่าน Reverse Proxy ก่อน IP/โดเมนจริงของงาน
